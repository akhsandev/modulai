# Folder Models 3D (.glb / .gltf)

Simpan file 3D `.glb` atau gambar `.png` Anda di folder ini (misal: `public/models/boss.glb`).

File di folder ini dapat diakses secara publik di aplikasi WebVR menggunakan URL relatif:
`./models/boss.glb` atau `/models/boss.glb`.

Saat dipush ke Git/GitHub, seluruh file di folder ini akan otomatis ikut ter-deploy ke Vercel/Netlify!
