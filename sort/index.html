PILIH ALGORITMA SORTING

Pilih salah satu dari 5 algoritma berikut untuk memulai tantangan sorting manual.

EASY

Bubble Sort

Bandingkan elemen bersebelahan dan tukar jika posisinya salah hingga elemen terbesar mengapung ke ujung.

Time: O(n²) Space: O(1)
EASY

Selection Sort

Cari elemen terkecil dari bagian belum terurut, lalu tukar ke posisi paling awal bagian tersebut.

Time: O(n²) Space: O(1)
MEDIUM

Insertion Sort

Sisipkan setiap elemen ke posisi yang tepat pada sub-array kiri yang sudah terurut secara bertahap.

Time: O(n²) Space: O(1)
HARD

Merge Sort

Bagi data menjadi dua bagian (Divide), urutkan masing-masing sub-array, lalu gabungkan kembali (Merge).

Time: O(n log n) Space: O(n)
HARD

Quick Sort

Pilih elemen Pivot, partisi data sehingga elemen < pivot di kiri dan > pivot di kanan, lalu ulangi rekurstif.

Time: O(n log n) Space: O(log n)
