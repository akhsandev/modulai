🚀 Solusi Anti-CORS di Vercel (1 File)

Teruskan request ke xKiro lewat server Vercel agar 100% bebas CORS.

  1. Di repository Vercel Anda (sejajar dengan index.html), buat file api/chat.mjs.
  2. Tempelkan kode di bawah ini ke dalam api/chat.mjs (tidak perlu npm install).
  3. Commit & push ke Vercel, lalu klik tombol Aktifkan Mode Proxy Vercel di bawah.
