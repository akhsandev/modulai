🚀 Solusi Anti-CORS di Vercel (1 File)

HTTPS tidak menghapus CORS—browser butuh proxy server di domain Vercel yang sama.

Mengapa tetap kena CORS meski sudah HTTPS di Vercel?
Karena domain web Anda (*.vercel.app) berbeda asal dengan api.xkiro.com, dan server xKiro tidak membuka akses CORS langsung dari browser. Solusinya: panggil /api/chat di domain Vercel Anda sendiri agar server Vercel yang meneruskan request ke xKiro (server-to-server, 0% CORS).
  1. Di root repository Git/Vercel Anda (sejajar dengan index.html), buat folder api lalu buat file baru bernama api/chat.mjs.
  2. Tempelkan kode di bawah ini ke dalam api/chat.mjs (tidak perlu npm install apa pun).
  3. Commit & push ke GitHub/Vercel. Setelah deploy selesai, aktifkan toggle Gunakan Proxy Vercel (/api/chat) di Pengaturan (atau klik tombol aktifkan di bawah).
api/chat.mjs

💡 Tips Keamanan Opsional: Di Dashboard Vercel → Settings → Environment Variables, Anda bisa menambahkan XKIRO_API_KEY agar API Key tersimpan aman di server dan tidak perlu ditaruh di kode browser.
