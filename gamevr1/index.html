🎙️ Voice Controller (Perintah Suara)

  • "maju" / "jalan": Pesawat meluncur maju
  • "mundur" / "balik": Pesawat mundur
  • "berhenti" / "stop": Rem darurat berhenti
  • "kiri" / "kanan": Manuver belok kiri / kanan
  • "tembak" / "fire": Tembak laser penghancur asteroid
  • "turbo" / "cepat": Pendorong kecepatan warp

🥽 Saran Opsi Kontrol Lainnya

  • Gaze / Arah Kepala (VR): Arahkan pandangan mata/kepala untuk mengemudi kapal di VR.
  • VR Controller (Quest): Tombol trigger untuk tembak, thumbstick untuk setir.
  • Keyboard & Mouse (PC): W/S (Gas), A/D (Belok), Spasi (Tembak), Geser Mouse (Arahkan).
  • Layar Sentuh (HP): Tombol on-screen di bagian bawah layar.
